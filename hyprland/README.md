# Hyprland config snapshot

Snapshot of `~/.config/hypr` from the Hyprland session, which runs
[end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) (illogical-impulse)
alongside niri. Both sessions are selectable from ly at login.

## Why this is not under `.config/`

`install/install.sh` symlinks **every** entry in `.config/*` into `$HOME`. If
`hypr` lived there, a fresh install would symlink it, and end-4's installer --
which uses `rsync -a --delete` into `~/.config/hypr/hyprland` -- would then write
straight through the symlink and delete files inside this repo.

So this is a **snapshot, not a deployed config**. Nothing symlinks it and
`install.sh` ignores it. To restore onto a new machine, install end-4's dots
first, then copy over the top:

    rsync -a hyprland/ ~/.config/hypr/

## Excluded

- `hyprland/colors.lua`, `hyprlock/colors.conf` -- regenerated by matugen on
  every wallpaper change
- `custom/` -- end-4's user-override area, installed with `--ignore-existing`

## Local changes worth knowing

- `hyprland/variables.lua`: `qsConfig` is set to `end4-pC`
  (github.com/pctrade/end4-pC), a QuickShell config living in
  `~/.config/quickshell/end4-pC`. That is its own git checkout and is not
  tracked here.
- `hyprland/keybinds.lua`: `SUPER + escape` toggles the end4-pC settings
  overlay.

## Refreshing this snapshot

    rsync -a --delete --exclude='colors.lua' --exclude='hyprlock/colors.conf' \
      --exclude='custom/' ~/.config/hypr/ hyprland/
